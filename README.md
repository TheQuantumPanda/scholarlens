# ScholarLens

ScholarLens is an evidence-grounded multi-paper research synthesis system designed to analyze, compare, and answer questions across academic papers while preserving traceability to supporting evidence.

## Status

Early development — environment and project infrastructure setup.

## Python

ScholarLens currently targets Python 3.11.

## Development

The project is being developed incrementally, beginning with a basic multi-document RAG pipeline before adding structured research synthesis, evidence grounding, verification, and evaluation.
